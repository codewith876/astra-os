# 🌌 Astra OS

A modern, lightweight, web-based operating system interface built with pure HTML, CSS, and JavaScript. Featuring a futuristic glassmorphic UI, smooth boot sequence, desktop widgets, window management, and built-in mini-apps.

---

## ✨ Features

- **🚀 Interactive Boot Sequence**: Terminal logs, progress ring, and system metadata loading state upon launch.
- **🖼️ Glassmorphic UI**: Translucent glass-styled elements with dynamic blurring and fixed wallpaper rendering.
- **🪟 Window Management**: Drag-and-drop window capabilities with dynamic depth layering (`z-index`) and control buttons.
- **⌚ Real-time Clock Widget**: Analog clock face synced with digital display and top status bar timing.
- **📅 Interactive Calendar Widget**: Dynamic month and day rendering with active day highlight and navigation controls.
- **📝 Desktop Mini-Apps**:
  - **Notes**: Lightweight glass window for quick text notes.
  - **Calculator**: Functional grid calculator supporting basic arithmetic operations.
- **🖱️ Custom Context Menu**: Custom desktop right-click menu with options to launch apps and refresh the OS.
- **📱 Top Status Bar & Dock**: Integrated status indicators (Battery, Wi-Fi, Volume) and launch dock icons.

---

## 🛠️ Built With

- **HTML5**: Semantic web structure and layout.
- **CSS3**: Glassmorphism, animations, grid/flexbox layouts, custom variables.
- **JavaScript (Vanilla ES6+)**: DOM manipulation, clock algorithms, window drag-and-drop mechanics, and event handling.
- **Google Fonts**: Orbitron and Poppins.
